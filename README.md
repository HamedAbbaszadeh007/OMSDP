# OMSDP
Open Municipal Spatial Data Platform

## Vision

OMSDP is an open-source platform for managing municipal spatial data, WebGIS, Spatial Data Infrastructure (SDI), and AI-assisted decision support for smart municipalities.

## Goals

- Build an open municipal SDI platform
- Provide WebGIS services
- Support spatial analysis
- Integrate AI for decision support
- Follow OGC standards
- Be scalable and cloud-native
