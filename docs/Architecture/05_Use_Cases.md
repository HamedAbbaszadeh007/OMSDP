# Use Cases

## Purpose

This document describes how different users interact with OMSDP to accomplish their goals.

Use cases define the functional behavior of the platform from the users' perspective before implementation begins.

## Main User Groups

- Public Users
- Registered Users
- Municipal Staff
- GIS Specialists
- Urban Analysts
- API Consumers
- Developers
- System Administrators
- AI Agent

## Example Use Cases

### Public User
- View public maps
- Search locations
- Submit public reports
- Access open spatial data

### Registered User
- Save favorite locations
- Track submitted requests
- Access personalized services

### Municipal Staff
- Update descriptive information
- Manage municipal records
- Review citizen reports

### GIS Specialist
- Edit spatial layers
- Validate spatial data
- Publish map services
- Manage metadata

### Urban Analyst
- Perform spatial analysis
- Generate reports
- Create thematic maps
- Support decision making

### API Consumer
- Access OMSDP APIs
- Integrate external applications
- Query spatial and descriptive data

### Developer
- Extend platform functionality
- Develop new modules
- Maintain system components

### System Administrator
- Manage users and roles
- Configure security
- Monitor system performance
- Manage backups

### AI Agent
- Answer natural language spatial questions
- Assist users with GIS operations
- Generate analytical reports
- Detect anomalies in urban data
- Support decision-making processes
